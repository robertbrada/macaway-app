# LockMate

Guard mode for a MacBook. LockMate locks your Mac within seconds of you walking away from
it, following the iPhone or Apple Watch already in your pocket over Bluetooth.

**[Download the latest release](https://github.com/robertbrada/lockmate-app/releases/latest)** ·
[lockmate page](https://robertbrada.github.io/lockmate-app/)

- Nothing to install on an iPhone or Apple Watch signed in to the same Apple ID as the Mac.
- macOS 13 or later, Apple silicon and Intel.
- No account, no server, nothing sent anywhere.
- LockMate never unlocks your Mac and never stores your password.

This repository holds the downloads, the update feed and the page. The source is not public.
